# Violence Detection

## Project Description

Violence Detection is a Django-based project developed for detecting violence-related activities.

## Technologies Used

- Python
- Django
- MySQL
- PyMySQL
- HTML
- CSS
- JavaScript

## Project Structure

- `manage.py` - Django project management file
- `Database.py` - Database connection
- `Violance_Detection/` - Django project files

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install dependencies.
4. Configure the database.
5. Run the Django server.
