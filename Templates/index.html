Overview — Server-Centric Workflow

Upload Dataset

Admins upload labeled datasets (violence / non-violence). The server extracts clips, preprocesses frames, and prepares TF/PyTorch datasets.

Train & Validate

Start training jobs with configurable hyperparameters (epochs, lr, batch). Monitor validation metrics (precision, recall, F1) and save best checkpoints.

Predict

Users upload test videos which the prediction service infers with the selected model. Results include label and confidence, stored in user history.
